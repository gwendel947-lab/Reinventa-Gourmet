
  # TCC - Reinventa Gourmet

  This is a code bundle for TCC - Reinventa. The original project is available at https://www.figma.com/design/N3eBI4L6bYPwhdURDoQjxK/TCC---Reinventa.

  # OBJETIVO DO PROJETO
     
     O Reinventa Gourmet é uma plataforma onde os itens "esquecidos" das dispensas são utilizados para a realizção de novas receitas. Utilizando receitas já salvas no banco de dados e com a utilização de IA para a criação de novas. O intuito é auxiliar os usuários a criarem, conhecerem e salvarem receitas dentro so site.

  # MVP

    - Hub Inicial
    - Página "Comunidade"
    - Painel Inventário para adiconar ingredientes
    - Aba de Cadastro e Login
    - Página "Meu Perfil"
